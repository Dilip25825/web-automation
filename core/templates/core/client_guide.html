KRP और PMFBY Excel Automation

Loan approval, loan upload, IS/PRI claim और PMFBY policy upload को सही तरीके से चलाने की client-facing guide। इस भाग को documentation link से बिना login भी पढ़ा जा सकता है।

Portal Login Loan Approval Loan Upload IS / PRI Claims PMFBY समस्या समाधान
शुरू करने से पहले: अपनी authorized User ID से ही login करें। CAPTCHA और OTP browser में स्वयं पूरा करें। Stable internet रखें और काम शुरू करने से पहले Excel file की backup copy बना लें।

KRP Operations

Loan approval, loan application upload और IS/PRI claim का कार्य।

PMFBY Operations

Policy Excel तैयार करना, single test, bulk upload और resume processing।

Excel Result

हर entry का result, reference number और failure का कारण Remark में देखें।

काम करने का तरीका

Processing शुरू करने से पहले checklist

  • Blank Start/End Row होने पर पूरी applicable sheet process होगी।
  • एक row fail होने पर बाकी rows चलती रहेंगी।
  • Failed row का exact कारण Excel के Remark में मिलेगा।
  • Stop button नई row शुरू होने से रोकेगा; चल रही row पूरी हो सकती है।
  • Stable internet connection रखें।
  • Selected workbook को Microsoft Excel में बंद रखें।
  • सही Financial Year या Season चुनें।
  • पहले एक row test करें, फिर bulk processing चलाएँ।

Step 1

Portal Login

  1. 1. Credentials: User ID और Password भरें।
  2. 2. Period: KRP के लिए Financial Year या PMFBY के लिए Season चुनें।
  3. 3. Login: संबंधित Login button दबाएँ और browser खुलने दें।
  4. 4. Verification: CAPTCHA/OTP manually पूरा करें और User Profile में ACTIVE आने के बाद काम शुरू करें।

ध्यान दें: Session समाप्त होने पर दोबारा login और OTP की आवश्यकता हो सकती है। Password, OTP और CAPTCHA किसी से साझा न करें।

Loan Application Approval

  1. Source में Branch या PACS चुनें।
  2. PACS चुनने पर names load करके सही PACS select करें।
  3. Loan Application Apply Filter चलाएँ।
  4. Number of Entries भरें या Approve All चुनें।
  5. Bulk Approval शुरू करके Process Status और final result देखें।

IS / PRI Claim Upload

  1. IS/PRI Excel browse करें और सही Claim Type चुनें।
  2. Start Row और End Row भरें; blank होने पर पूरी sheet process होगी।
  3. Apply Filter से portal applications load करें।
  4. Submit Claims From Excel चलाएँ।
  5. Claim Number और exact Remark संबंधित Excel row में save होंगे।

Claim Number पहले से होने पर row दोबारा upload न करें। एक entry fail होने पर बाकी entries जारी रह सकती हैं।

PMFBY Excel

PMFBY Policy Upload

  1. 1. PMFBY login और सही Season selection complete करें।
  2. 2. Official report या supported old-format Excel browse करें।
  3. 3. Premium Debit Date और Sowing Date DD-MM-YYYY में भरें।
  4. 4. Requirements checklist confirm करके Prepare Excel चलाएँ।
  5. 5. पहले Single Upload से test करें; सफल होने पर Bulk Upload चलाएँ।
  6. 6. Interrupted processing के लिए Resume Upload इस्तेमाल करें।

Policy Number, Application Number, Uploaded Area, land-record farmer name और Remark workbook में save होने के बाद result verify करें।

Excel Handling Rules

  • Identifiers और mobile numbers को text के रूप में रखें ताकि leading zero न हटे।
  • Dates को required format में रखें और amount cells में text/symbol न मिलाएँ।
  • Processing के दौरान selected workbook बंद रखें।
  • Large batch से पहले original workbook की backup copy रखें।
  • Result उसी selected workbook में save होता है; file rename/move processing के बाद करें।

Errors, Recovery & Support

Row Failed: Remark पढ़ें, source data सुधारें और केवल failed row दोबारा चलाएँ।
Session / Verification Error: Portal session, internet और browser login check करके पुनः प्रयास करें।
Support को भेजें: अंतिम Process Status, Excel row number, Remark, operation name और selected Year/Season भेजें। Password, OTP या CAPTCHA कभी न भेजें।
